processo de upload é basicamente: add > commit > push MAS FACAM ISSO NA DEV

| Comando | Descrição |
| --- | --- |
| git clone [URL] | Baixa as pastas e documentos de um repositório |
| git commit -m "msg" | Salva a sua versão do repositório **localmente** |
| git push | Faz upload do seus arquivos para o repositório remoto |
| git pull | Sincroniza o seu repositório com o remoto, **puxando** os arquivos |
| git add <arquivo> | Adicionar arquivos ao repositório local. É possível selecionar todos os arquivos com parâmetro <.> |


| Tipo de Commit | Descrição | Exemplo |
| --- | --- | --- |
| feat | Adiciona uma nova funcionalidade ao projeto. | feat: add index.js |
| fix | Corrige um bug ou problema no projeto. | fix: fixed issue pipipipopopo |
| docs | Altera documentação do projeto | docs: update README.md |
| style | Realiza mudanças na aparência, sem alterar a funcionalidade. | style: embelezou o mininin |
| refactor | Realiza mudanças no código que não alteram a funcionalidade. | refactor: reescreveu o mininin |
| test | Adiciona ou modifica testes no projeto. | test: add test pro mininin |
